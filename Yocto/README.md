# Yocto Project Build for KV260 for 2025.2 Tools
This app is using meta-kria recipes for Yocto toolchain for building the Bootable Image.


**Note -** As mentioned at the GSG document, one can also use the prebuilt or given Yocto image on the KV260 starter kit.
